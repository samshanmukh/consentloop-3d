# Full-body anatomy model attribution

`anatomy.glb` is the muscular-system model distributed by the
[Poilon/carabin anatomy viewer](https://github.com/Poilon/carabin/tree/87cbaf4ee882b741d0fd1d6403c00ec0d23eaf83/corps-humain),
pinned to commit `87cbaf4ee882b741d0fd1d6403c00ec0d23eaf83`.

The model is derived from **BodyParts3D**, © The Database Center for Life
Science, and is licensed under the
[Creative Commons Attribution-ShareAlike 2.1 Japan license](https://creativecommons.org/licenses/by-sa/2.1/jp/deed.en).

ConsentLoop stores the upstream Draco-compressed GLB unchanged. At runtime the
viewer rotates, recenters, recolors, and merges the model's meshes for web
rendering. Model derivatives remain available under the same CC BY-SA terms.
The ConsentLoop application source code is not derived from this model and is
licensed separately.
